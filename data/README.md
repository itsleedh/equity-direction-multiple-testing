# Data Policy and Expected Schema

## Redistribution policy

The raw market data used in the original experiments is not redistributed
through this repository. Users must provide their own legally obtained data
matching the documented schema.

The MIT license applies to repository code and documentation, not to third-party
market data, macro series, index histories, short-interest observations, or
provider APIs. Users are responsible for reviewing the terms of every source.

## Data categories used by the code

- Equity OHLCV bars from configurable yfinance, Alpaca, or Polygon-compatible
  provider paths.
- FRED market/macro series such as rates, spreads, volatility, currency, and
  oil observations.
- CBOE index histories such as SKEW.
- FINRA consolidated short-interest observations transformed to days-to-cover.
- A manually documented point-in-time annual equity membership table.

Provider support in code is not a statement that redistribution is allowed.

## Equity-bar schema

The normalized in-memory and Parquet schema is:

| Field | Type | Meaning |
|---|---|---|
| index | datetime | Unique bar timestamp, increasing |
| `open` | float | Bar open |
| `high` | float | Bar high |
| `low` | float | Bar low |
| `close` | float | Bar close |
| `volume` | numeric | Bar volume; missing values become zero |

Required invariants:

- `high >= max(open, close)`;
- `low <= min(open, close)`;
- OHLC values are finite and positive;
- timestamps are sorted and deduplicated; and
- missing OHLC rows are removed rather than forward-filled.

Daily timestamps may be exchange-date-like and timezone-naive, depending on the
provider. Intraday bars should carry an unambiguous timezone; Alpaca timestamps
arrive in UTC and the intraday feature path converts them to
`America/New_York` for regular-hours logic.

## Adjustments and corporate actions

Most historical configurations set `auto_adjust: true`. For yfinance this asks
the provider for adjusted OHLC bars so splits and dividends are reflected in
the returned price history. Alpaca requests `adjustment=all` under the same
flag. Exact adjustment conventions remain vendor-dependent and should be
recorded with every reproduction.

The code does not independently reconstruct corporate actions.

## External-series schema

FRED and CBOE caches contain:

| Field | Meaning |
|---|---|
| index | Observation date |
| `value` | Raw numeric observation |

At load time the code adds `available_from`, the observation date plus the
configured business-day publication lag. Features are joined onto price bars
only when `available_from <= bar timestamp`.

FINRA caches use settlement date as index and retain
`short_interest`, `avg_daily_volume`, and `days_to_cover`. The modeled feature is
days-to-cover after the configured publication lag.

## Universe and date ranges

The static default universe contains ten contemporary large U.S. equities. The
point-in-time configuration uses annual top-ten membership with a 19-symbol
union. See `configs/universe_pit.yaml` for scope and manual-source notes.

Coverage varies by provider and configuration. Do not describe the entire
repository as one homogeneous date range:

- daily and weekly studies use multi-year price histories;
- hourly yfinance coverage is shorter;
- yfinance minute coverage is short;
- the long 5-minute Alpaca IEX study begins in 2020; and
- FINRA short-interest coverage begins later than the longest price studies.

## Local placement

Put non-public data under one of these ignored locations:

```text
data/cache/
data/cache_<experiment>/
data/raw/
data/private/
data/vendor/
```

Historical configs already reference named cache directories relative to the
config file. Never place provider credentials in a config. Use environment
variables documented in `.env.example`.

## Deterministic synthetic sample

`data/sample/synthetic_ohlcv.csv` is fictional and generated by
`scripts/generate_synthetic_sample.py` with a fixed seed.

It:

- does not reproduce a real company or real market path;
- uses the symbol `SYNTH`;
- is small enough for source control;
- contains an explicit `synthetic` marker;
- supports an end-to-end offline smoke test; and
- is only for checking interfaces and invariants, not research conclusions.

Regenerate it with:

```bash
python scripts/generate_synthetic_sample.py
```

Run the smoke pipeline with:

```bash
python scripts/run_experiment.py --config configs/example_config.yaml
```
