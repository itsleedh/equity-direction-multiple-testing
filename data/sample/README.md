# Synthetic Sample

`synthetic_ohlcv.csv` contains deterministic, fictional daily OHLCV bars for
the non-company symbol `SYNTH`.

The file is generated with seed `20260731`. It is intended only to verify
configuration, feature, split, strategy, cost, statistical-reporting, and file
output interfaces. It is not a sample of the licensed historical research data,
does not mimic any specific listed company, and cannot reproduce the research
conclusion.
